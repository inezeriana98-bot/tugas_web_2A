About Me

Sebagai mahasiswi Sistem Informasi semester 3, saya memiliki ketertarikan mendalam pada web development dan pemrograman Python. Nilai utama yang saya pegang adalah keinginan untuk terus belajar dan beradaptasi, tidak hanya dalam membangun antarmuka web tetapi juga mengintegrasikan logika tingkat lanjut seperti computer vision dan pengolahan data visual secara real-time.
